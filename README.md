# Wolfex Games — Red / Black / White / Blue Edition

A responsive gaming-studio website built with plain HTML, CSS and JavaScript. No AI-builder credits or paid libraries are required to edit it.

## Open the website
1. Extract the ZIP.
2. Open the `wolfex-games` folder in VS Code.
3. Open `index.html` in a browser, or use the free Live Server extension.

## Pages
- `index.html` — public Wolfex Games homepage
- `mega-obby.html` — Mega Obby information page
- `project-frontier.html` — Project Frontier concept page
- `admin.html` — studio-access information placeholder
- `styles.css` — shared responsive design and brand palette
- `script.js` — small page behaviors

## Brand palette
- Charcoal / near-black backgrounds
- Red primary highlights and action buttons
- Blue secondary accents and game details
- White main text and silver-gray supporting text

## Important
The game pages describe projects; they are not playable game builds yet. The admin page is not a working login or dashboard. Before making owner-only controls public on a hosted site, add real server-side authentication and authorization. Do not rely on a password hidden in browser JavaScript.
